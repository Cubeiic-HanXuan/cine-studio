# CineStudio

基于 **Agnes Video 2.5** 的精致视频生成工作台。包含三大视图：

- **单镜生成**：四种模式
- **分镜脚本**：面向短剧创作的镜头级脚本管理与批量生成
- **已生成视频**：汇总管理所有已生成视频，支持按剧本分组、按时间排序、一键下载到磁盘

| 模式 | 说明 | API `mode` |
| --- | --- | --- |
| 🎬 文生视频 | 纯文本描述生成视频 | `text` |
| 🖼 图生视频 | 上传一张图作为**真实首帧**，从该画面生成动态视频 | `keyframe`（仅 `first_frame`） |
| 🧩 多图视频 | 上传多张参考图，用 `<Picture N>` 引用角色 / 场景 / 风格 | `reference`（`images[]`） |
| 🎞 关键帧动画 | 上传首帧 + 尾帧，在两者之间平滑过渡 | `keyframe`（`first_frame` + `last_frame`） |

## 分镜脚本（短剧创作）

切换到「分镜脚本」视图，可进行镜头级脚本管理：

- **多剧本项目**：新建 / 重命名 / 删除 / 切换剧本；
- **结构化分镜表**：每镜头含镜号、场景、景别、运镜、画面描述（prompt）、台词/旁白、时长、生成模式（文生/图生）、参考图、备注；
- **单条 + 一键批量生成**：结果（进度 / 视频预览 / 下载）自动回填到对应镜头，按镜号顺序排列；
- **导出 / 导入 JSON**：剧本可备份或迁移。

> 镜头级「画面描述」即发给模型的 prompt；「台词/旁白」仅作脚本管理，不注入模型。剧本数据保存在本机浏览器（`localStorage`）。

## 已生成视频

切换到「已生成视频」视图，汇总管理所有已生成的视频（含单镜生成 + 分镜脚本）：

- **按剧本分组** / 平铺列表、**按时间排序**（最新/最早）；
- 每个视频带**镜头编号**、场景、提示词（可展开）、时间、分辨率/时长/画幅；
- **本地化存储**：视频生成完成后**自动下载**到本机「视频存储目录」（默认项目内 `videos/`，可在「设置」里改），此后播放 / 预览 / 下载都走**本地文件**，不再依赖会过期的远程地址；
- **一键下载全部到磁盘**：把尚未落盘的视频补齐到存储目录，按「剧本/镜头号_场景.mp4」保存，并生成 `清单.csv`；
- **导出记录 CSV**：下载全部视频元数据；
- 单条也可预览 / 下载 / 新窗口打开 / 复制链接。

## 为什么需要本地服务

Agnes 的 API Key **不应写入前端代码**，且浏览器直连 API 会遇到跨域（CORS）限制；`keyframe` / `reference` 模式还要求素材是**可公开访问的 URL**。因此本项目内置一个轻量本地服务（`server.js`），负责：

1. 托管页面；
2. 保管 API Key（仅存于本机 `data/config.json` 或环境变量），代发创建 / 查询请求；
3. 把上传的图片自动转存到公共图床（依次尝试 `uguu.se` → `litterbox.catbox.moe` → `catbox.moe` → `0x0.st`），拿到 Agnes 所需的公开 URL。

> 素材会经由公共图床获得一个**公开链接**，任务完成前该链接需保持有效。`uguu.se` 为永久保存；`litterbox` 最长保存 72 小时（对视频生成任务足够）。若所有图床都不稳定，你也可以直接粘贴自己准备的公开 URL（如对象存储 / 图床的直链）。

## 快速开始

要求：Node.js ≥ 18.17（建议 20+）。

```bash
cd cine-studio
npm install
npm start
```

然后打开 <http://localhost:8787>，点击右上角 **「设置」** 填入 Agnes API Key 即可。

也可以不落盘、只通过环境变量注入：

```bash
AGNES_API_KEY="sk-…" npm start
# 可选：AGNES_BASE_URL（默认 https://api.agnes-ai.cn/v1）
```

## 使用步骤

1. **连接**：右上角「设置」填入 API Key（或使用环境变量）。
2. **选模式**：在左侧切换「文生视频 / 图生视频 / 多图视频 / 关键帧动画」。
3. **写描述**：按「主体与场景 → 动作与变化 → 镜头语言 → 视觉风格 → 声音与节奏」的顺序描述；点「灵感」可填入示例。
4. **传素材**：拖拽或点击上传图片（图生 / 多图 / 关键帧模式需要）。
5. **调参数**：选择时长（4–12 秒）、分辨率（720P / 960P / 2K）、画幅（16:9、9:16、1:1、4:3、3:4、21:9），可选随机种子。
6. **生成**：点击「开始生成」，右侧队列会自动轮询进度，完成后即可在线播放 / 新窗口打开 / 复制链接 / 下载。

任务与结果仅保存在当前浏览器（`localStorage`），刷新后未完成任务会自动续查。

## 目录结构

```
cine-studio/
├── server.js        # 本地服务：静态托管 + 代理 + 上传转存
├── package.json
├── public/
│   ├── index.html     # 页面结构
│   ├── styles.css     # 视觉样式（影院控制台美学）
│   ├── app.js         # 单镜生成：模式、上传、轮询、历史
│   └── storyboard.js  # 分镜脚本：项目 CRUD、镜头表、批量生成
└── data/              # 运行时生成，保存 API Key（已 gitignore）
```
